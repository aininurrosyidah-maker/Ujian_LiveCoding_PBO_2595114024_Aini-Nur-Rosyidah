## Deskripsi Program
### Kasus 1 - Sistem Kasir Minimarket
Program untuk menghitung total belanja pelanggan, menentukan persentase diskon berdasarkan jumlah belanja, menghitung potongan harga, dan menampilkan total pembayaran akhir.

### Kasus 2 – Sistem Penilaian Akademik
Program untuk menghitung nilai akhir mahasiswa berdasarkan nilai tugas, UTS, dan UAS, menentukan grade berdasarkan hasil nilai, serta menampilkan status kelulusan mahasiswa.
